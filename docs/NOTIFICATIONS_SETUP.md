# JobTracker Android push notifications

Status: server and client integration require deployment and a new Android build. No push notifications are delivered until these steps are completed.

## Supported notification preferences
- newJobs — connected employer is alerted when an employee enters a **shared** job (independent/personal jobs are never sent).
- assignments — employees are alerted when the employer creates a shared assignment.
- jobUpdates — owner/employee update alerts for shared jobs.
- messages — preference reserved for the future messaging backend.
- reminders — preference reserved for scheduled job / unpaid invoice reminder processing.

## Setup
1. Run `npx expo install expo-notifications expo-constants` in the app root before building.
2. Set up Android FCM V1 credentials for EAS; build a new Android development/preview binary.
3. Install Firebase Functions dependencies with `npm install` from `functions/`.
4. Confirm Firebase CLI is authenticated to the **correct** Firebase project, then `firebase deploy --only firestore:rules,functions`. Cloud Functions deployment may require a billing-enabled Firebase project.
5. Each recipient must sign in to their own JobTracker account and navigate to Settings > Phone notifications > Enable Notifications on This Phone. Android permission will be requested.
6. Verify dad's account is the actual linked owner account and the employee relation is active.
7. Test an employee **shared job** (not independent) and verify the owner sees a push notification. Test a newly assigned job and a job update.

Security: user-owned push tokens and preferences are private per UID in Firestore. Client code cannot send push to someone else's device. Push messages are generated by Cloud Functions from authorized shared job records.

Messages and reminders need live event sources and server-side scheduling before those two categories can deliver notifications. Currently the Messages screen in the app is a placeholder; enabling the preference does not deliver message pushes.\n\nDo not test this via Expo Go or the old APK: the push-enabled native app must be rebuilt and installed, with FCM credentials configured.
